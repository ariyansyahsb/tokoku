# Tokoku - Sistem Informasi Toko Online

Sistem Informasi Toko Online berbasis web untuk mengelola katalog produk, transaksi penjualan, dan pesanan pelanggan secara digital.

Dibangun menggunakan **Laravel** sebagai Tugas / Proyek Mata Kuliah D3 Teknik Manajemen Informatika.

**Live Repository:** https://github.com/ariyansyahsb/tokoku

---

## Fitur Utama

### Untuk Pelanggan (User)
- Registrasi & Login Akun
- Lihat Katalog Produk & Detail Produk
- Cari & Filter Produk Berdasarkan Kategori
- Keranjang Belanja (Add to Cart)
- Checkout & Buat Pesanan
- Lihat Riwayat Pesanan

### Untuk Admin / Pemilik Toko
- Dashboard Admin
- CRUD Produk (Tambah, Edit, Hapus Produk)
- CRUD Kategori Produk
- Manajemen Stok Produk
- Manajemen Pesanan (Konfirmasi, Proses, Selesai)
- Manajemen User / Pelanggan

## Teknologi yang Digunakan

- **Backend:** PHP 8.x, Laravel 11
- **Frontend:** Blade Template, Bootstrap / Tailwind CSS, JavaScript
- **Database:** MySQL
- **Server Lokal:** Laragon (Apache + MySQL)
- **Version Control:** Git & GitHub
